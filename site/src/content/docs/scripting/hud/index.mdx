Eight working starting points for showing things to players from a cs_script map. Six use a `custom_hud_layout`; the last two use entities the game already draws, driven from the script through entity inputs or their script class. Each page has the files laid out the way an addon expects them, the entities to place in Hammer, and what to change.

## Before you start

- Read [Custom HUD layouts](../guides/custom-hud/) for how the entity, the layout file and the script fit together.
- Read [HUD gotchas](./gotchas/) before writing your own CSS. Panorama looks like web CSS and isn't, and a single unsupported attribute stops a layout from loading without an error.
- Every script imports `cs_script/point_script`. Put Valve's `point_script.d.ts` next to it with the `tsconfig.json` from the [samples folder](https://github.com/CS2OpenDev/CS2OpenDev-Docs/tree/main/site/src/samples/hud) and your editor checks each call. The declaration file ships with the Workshop Tools in `content/csgo_addons/cs_script_demo/maps/scripts/`; this repository does not redistribute it.

## Using a sample

1. Copy its files into your addon: layouts under `content/csgo_addons/<addon>/panorama/layout/custom_game/`, stylesheets under `panorama/styles/custom_game/`, scripts under `maps/scripts/`.
2. Place the entities from the sample's **Map setup** table and give them the names it lists.
3. Add a `point_script` entity and set its `cs_script` property to the sample's script (`maps/scripts/gallery_<name>.vjs`).

Each sample uses its own entity names and its own `gallery_` file names, so several can run in one map. `point_script` entities run isolated from each other, so use one per sample.

## Screenshots

Each sample's picture is taken in game from the files on its page. A sample without one hasn't been checked in game yet: its script typechecks against `point_script.d.ts`, but nobody has confirmed the layout renders the way the CSS intends. If you run one, a screenshot (1920×1080, unscaled, game HUD visible) is the most useful contribution there is; the [capture notes](https://github.com/CS2OpenDev/CS2OpenDev-Docs/tree/main/site/src/samples/hud#screenshots) say where it goes.

## Community HUD projects

Larger, real-world layouts, most of them built for server plugins. The layout files work the same from a map script; only the code that drives them differs. Check each license before reusing code.
