shipped Counter-Strike 2 binaries. Every page on this site is projected from one
CS2OpenDev-SchemaTracker artifact set, so the offsets, message shapes and console
tables all describe the same game build; community annotations from this repository's
overlay files are layered on top where they exist.

## How pages are generated

Every reference page here is rendered at build time from one SchemaTracker artifact
set; nothing is hand-edited except a per-entity overlay layer that adds descriptions,
notes and warnings on top of the raw binary data. If you want to contribute an
annotation, read the
[overlays README](https://github.com/CS2OpenDev/CS2OpenDev-Docs/blob/main/docs/overlays/README.md)
on GitHub.
